# QinQapay — Application Android

Application Android de demonstration pour QinQapay (achetez, epargnez, construisez).

Cette application charge le site [QinQapay](https://posidiusdigitalservices.com/qinqapay1/) dans une app native Android.

## Telechargement

Telechargez le dernier APK depuis la page [Releases](../../releases/latest).

## A propos

QinQapay connecte les quincailleries de Cote d'Ivoire aux acheteurs, aux entreprises et a la diaspora, pour acheter des materiaux de construction, epargner pour un projet et se faire livrer sur chantier.
